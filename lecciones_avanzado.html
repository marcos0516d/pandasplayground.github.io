📖 Guía de Pandas Avanzado

pd.read_csv con chunksize

El parámetro chunksize permite leer archivos CSV grandes por partes, devolviendo un TextFileReader que itera sobre bloques de filas.

# Leer en chunks de 1000 filas
chunks = pd.read_csv('datos.csv', chunksize=1000)

# Procesar cada chunk
for chunk in chunks:
    procesar(chunk)

# Convertir a lista y concatenar
chunks_list = list(pd.read_csv('datos.csv', chunksize=1000))
resultado = pd.concat(chunks_list)

usecols para seleccionar columnas

El parámetro usecols carga solo las columnas especificadas, ahorrando memoria.

# Seleccionar columnas específicas
df = pd.read_csv('datos.csv', usecols=['nombre', 'edad'])

# Por índice de columna
df = pd.read_csv('datos.csv', usecols=[0, 2, 5])

Categorical dtype

Convierte columnas de texto repetido a tipo categórico para reducir significativamente el uso de memoria.

# Convertir a categorical
df['ciudad'] = df['ciudad'].astype('category')

# Verificar
print(df['ciudad'].dtype)  # category
print(df['ciudad'].cat.categories)  # valores únicos

Downcast numéricos

pd.to_numeric con downcast reduce el tamaño de tipos numéricos (int64 → int8, float64 → float32).

# Downcast integer
df['edad'] = pd.to_numeric(df['edad'], downcast='integer')

# Downcast float
df['peso'] = pd.to_numeric(df['peso'], downcast='float')

# Verificar ahorro de memoria
print(df.memory_usage(deep=True).sum())

memory_usage()

Mide el consumo de memoria de cada columna del DataFrame en bytes.

# Uso total de memoria
total = df.memory_usage(deep=True).sum()

# Por columna
por_col = df.memory_usage(deep=True)

# En megabytes
print(f'{total / 1024**2:.2f} MB')

map() - Element-wise

Aplica una función a cada elemento de una Series individualmente.

# Con lambda
s = pd.Series([1, 2, 3])
resultado = s.map(lambda x: x * 2)

# Con diccionario
mapeo = {1: 'uno', 2: 'dos', 3: 'tres'}
resultado = s.map(mapeo)

apply() - Column-wise

Aplica una función a lo largo de columnas o filas del DataFrame.

# Aplicar a cada columna
resultado = df.apply(lambda col: col.max() - col.min())

# Aplicar a cada fila
resultado = df.apply(lambda row: row.sum(), axis=1)

pipe() - Method chaining

Permite encadenar funciones personalizadas en una cadena de procesamiento.

# Definir función personalizada
def agregar_columna(df):
    df['total'] = df['a'] + df['b']
    return df

# Usar pipe
resultado = df.pipe(agregar_columna)

# Encadenar múltiples pipes
resultado = (df
    .pipe(filtrar_nulos)
    .pipe(normalizar)
    .pipe(agregar_columna))

agg() y transform()

agg() aplica funciones de agregación, transform() aplica funciones que mantienen el mismo tamaño.

# agg: múltiples agregaciones
resultado = df.groupby('grupo').agg({
    'valor': ['mean', 'max', 'min']
})

# transform: mantiene el mismo número de filas
df['valor_z'] = df.groupby('grupo')['valor'].transform(
    lambda x: (x - x.mean()) / x.std()
)

Sparse Arrays

Los arrays dispersos almacenan solo valores no nulos, ahorrando memoria en datos con muchos NaN.

# Crear SparseArray
arr = pd.arrays.SparseArray([1, np.nan, np.nan, 2, np.nan])

# Verificar densidad
print(arr.sparse.density)  # 0.4 (40% de valores no nulos)

# Convertir entre sparse y dense
denso = arr.to_dense()
sparse = pd.array(denso, dtype=pd.SparseDtype('float64', fill_value=0))
