📖 Guía de Pandas Avanzado

pd.read_csv() con chunksize

Permite leer archivos CSV enormes por bloques, evitando sobrecargar la memoria.

for chunk in pd.read_csv('ventas.csv', chunksize=1000):
    procesar(chunk)

Dtype category

Reduce el uso de memoria convirtiendo columnas con pocos valores únicos a tipo category.

df['genero'] = df['genero'].astype('category')

apply() con UDFs

Aplica funciones personalizadas fila por fila o columna por columna.

def clasificar(precio):
    if precio < 50: return 'Barato'
    elif precio < 200: return 'Medio'
    return 'Caro'

df['clasificacion'] = df['precio'].apply(clasificar)

nlargest / nsmallest

Obtiene los N valores más grandes o más pequeños de forma eficiente.

top3 = df.nlargest(3, 'ventas')
bottom3 = df.nsmallest(3, 'ventas')

pd.pivot_table()

Crea tablas dinámicas con agregación (sum, mean, count, etc.).

tabla = pd.pivot_table(df, values='precio',
    index='categoria', aggfunc='sum')

df.explode()

Transforma listas en filas separadas.

df = pd.DataFrame({'productos': [['A','B'], ['C']]})
df_exploded = df.explode('productos')

Window functions

Funciones de ventana: rolling, expanding, ewm para cálculos acumulativos.

df['media_movil'] = df['ventas'].rolling(3).mean()
df['acumulado'] = df['ventas'].expanding().sum()

pd.crosstab()

Tablas de frecuencia cruzada entre dos columnas categóricas.

tabla = pd.crosstab(df['categoria'], df['ciudad'])

DataFrame Styler

Aplica estilos visuales a DataFrames para visualización.

df.style.background_gradient(subset=['precio'])
df.style.highlight_max()

df.query()

Filtra filas usando una expresión en lenguaje natural de pandas.

resultado = df.query('precio > 50 and cantidad > 10')

df.eval()

Evalúa expresiones matemáticas de forma rápida sobre columnas.

df.eval('total = cantidad * precio', inplace=True)

df.assign()

Crea nuevas columnas encadenando asignaciones sin modificar el original.

df_result = df.assign(
    impuesto = df['precio'] * 0.21,
    total = df['precio'] * 1.21
)
