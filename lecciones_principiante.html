📖 Guía de Funciones de Pandas

import pandas as pd

Importa la librería pandas y le asigna el alias pd. Es la convención estándar usada por todos los desarrolladores de Python.

import pandas as pd

# Ahora puedes usar pd para acceder a pandas
print(pd.__version__)

pd.Series()

Crea una Serie, que es una estructura de datos unidimensional etiquetada. Es como una lista de Python pero con un índice y métodos estadísticos integrados.

# Serie con lista de valores
precios = pd.Series([15.5, 22.0, 8.75, 45.0, 12.3])

# Serie con índice personalizado
ventas_q1 = pd.Series(
    [1200, 1800, 950],
    index=['Enero', 'Febrero', 'Marzo']
)

# Métodos estadísticos
print(precios.mean())    # Promedio
print(ventas_q1.sum())   # Suma
print(precios.max())     # Máximo
print(precios.min())     # Mínimo

pd.DataFrame()

Crea un DataFrame, que es una estructura de datos bidimensional (tabla) con filas y columnas. Es la estructura más importante de pandas.

# DataFrame desde diccionario
estudiantes = pd.DataFrame({
    'materia': ['Matemáticas', 'Historia', 'Química'],
    'nota_final': [8.5, 9.2, 7.8],
    'asistencias': [18, 20, 16]
})

# Acceder a una columna
print(estudiantes['nota_final'])

# Información del DataFrame
print(estudiantes.shape)      # (3, 3)
print(estudiantes.columns)    # Nombres de columnas
print(estudiantes.dtypes)     # Tipos de datos

pd.read_csv()

Lee un archivo CSV (Comma-Separated Values) y lo convierte en un DataFrame. Es una de las funciones más usadas en análisis de datos.

# Leer un archivo CSV
movimientos = pd.read_csv('cuenta_bancaria.csv')

# Con opciones adicionales
transacciones = pd.read_csv(
    'transacciones.csv',
    sep=';',              # Delimitador personalizado
    index_col='id',       # Usar columna como índice
    encoding='utf-8'      # Codificación del archivo
)

# Leer desde una URL
url = 'https://ejemplo.com/datos climáticos.csv'
clima = pd.read_csv(url)

# Primeras 5 filas (por defecto)

Filtrado con condicionales

Permite seleccionar filas que cumplan una condición específica. El resultado es un nuevo DataFrame solo con las filas que cumplen la condición.

# Filtrar por una condicion
estudiantes_aprobados = estudiantes[estudiantes['nota_final'] >= 7.0]

# Filtrar por multiples condiciones
aprobados_con_asistencia = estudiantes[
    (estudiantes['nota_final'] >= 7.0) & (estudiantes['asistencias'] >= 18)
]

# Filtrar por valores en una lista
seleccion = estudiantes[estudiantes['materia'].isin(['Matemáticas', 'Química'])]

Operaciones estadisticas

pandas tiene metodos integrados para calculos estadisticos sobre columnas o filas completas.

# Promedio de una columna
promedio = inventario['stock'].mean()

# Suma total
total = inventario['ventas'].sum()

# Maximo y minimo
maximo = inventario['precio'].max()
minimo = inventario['precio'].min()

# Desviacion estandar
variacion = inventario['precio'].std()

# Resumen estadistico completo
print(inventario.describe())

df.sort_values()

Ordena el DataFrame por los valores de una o mas columnas. Puede ordenar de menor a mayor o viceversa.

# Ordenar por una columna (menor a mayor)
ordenado = mediciones.sort_values('temperatura')

# Ordenar de mayor a menor
top_salarios = empleados.sort_values('salario', ascending=False)

# Ordenar por multiples columnas
orden_completo = registros.sort_values(['año', 'puntaje'])

Crear columnas

Puedes crear nuevas columnas en un DataFrame usando operaciones entre columnas existentes o asignando valores directamente.

# Crear columna con operacion
estudiantes['aprobado'] = estudiantes['nota_final'] >= 7.0

# Crear columna con valor constante
estudiantes['año_escolar'] = '2024'

# Crear columna con funcion lambda
estudiantes['nivel'] = estudiantes['nota_final'].apply(
    lambda x: 'excelente' if x >= 9.0 else 'bueno'
)

df.groupby()

Agrupa filas por una columna y permite hacer agregaciones (sum, mean, count, etc.) sobre cada grupo. Es muy poderoso para analisis de datos.

# Agrupar y sumar
totales = pedidos.groupby('cliente')['monto_total'].sum()

# Agrupar y promediar
promedios = encuestas.groupby('departamento')['satisfaccion'].mean()

# Multiples agregaciones
resumen = cursos.groupby('instructor').duracion_horas': 'sum',
    'calificacion': 'mean'
})

Valores faltantes (NaN)

pandas representa los valores faltantes como NaN (Not a Number). Hay varias formas de manejarlos.

import numpy as np

# Detectar valores faltantes
print(mediciones.isna())           # True/False por celda
print(mediciones.isna().sum())     # Total por columna

# Rellenar valores faltantes
completo = mediciones.fillna(0)                       # Rellenar con 0
completo = mediciones.fillna({'presion': 120})    # Solo una columna

# Eliminar filas con valores faltantes
limpio = mediciones.dropna()

df.drop_duplicates()

Elimina filas duplicadas del DataFrame. Mantiene solo la primera aparicion de cada fila duplicada.

# Eliminar duplicados
sin_repetir = socios.drop_duplicates()

# Eliminar duplicados basandose en una columna
unicos = socios.drop_duplicates(subset='num_socio')

# Mantener la ultima aparicion
ultimos = registros.drop_duplicates(keep='last')

df.to_csv()

Exporta el DataFrame a un archivo CSV. Es util para guardar los resultados del analisis.

# Guardar en CSV
reporte.to_csv('informe_mensual.csv')

# Guardar sin el indice (recomendado)
reporte.to_csv('informe_mensual.csv', index=False)

# Guardar con codificacion especifica
reporte.to_csv('informe_mensual.csv', encoding='utf-8')
