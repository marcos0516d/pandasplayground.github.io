📖 Guía de Pandas Intermedio

pd.concat()

Concatena (une) múltiples DataFrames de forma vertical u horizontal. Es útil para combinar datos de la misma estructura.

# Concatenar verticalmente
pedidos_ene = pd.DataFrame({'cliente': ['Ana', 'Bob'], 'monto': [150, 200]})
pedidos_feb = pd.DataFrame({'cliente': ['Carlos', 'Diana'], 'monto': [180, 220]})
todos_pedidos = pd.concat([pedidos_ene, pedidos_feb])

# Concatenar horizontalmente
datos_extra = pd.DataFrame({'region': ['Norte', 'Sur']})
resultado = pd.concat([pedidos_ene, datos_extra], axis=1)

pd.merge()

Combina DataFrames basándose en una o más columnas comunes, similar a los JOINs en SQL.

# Merge por una columna
departamentos = pd.DataFrame({'depto_id': [1, 2, 3], 'nombre_depto': ['Ventas', 'IT', 'RRHH']})
empleados = pd.DataFrame({'nombre': ['Laura', 'Pedro', 'Sofia'], 'depto_id': [1, 2, 1]})
resultado = pd.merge(departamentos, empleados, on='depto_id')

# Merge por diferentes columnas
facturas = pd.DataFrame({'cliente_id': [101, 102], 'total': [500, 300]})
clientes = pd.DataFrame({'id': [101, 102], 'nombre': ['Ana', 'Bob']})
resultado = pd.merge(facturas, clientes, left_on='cliente_id', right_on='id')

# Tipos de join
pd.merge(izq, der, on='clave', how='inner')  # Solo coincidencias
pd.merge(izq, der, on='clave', how='left')   # Todo el izquierdo
pd.merge(izq, der, on='clave', how='right')  # Todo el derecho
pd.merge(izq, der, on='clave', how='outer')  # Todo

df.join()

Une DataFrames basándose en sus índices. Es una alternativa a merge cuando quieres unir por índices.

# Unir por índices
notas_mat = pd.DataFrame({'parcial1': [8, 7], 'parcial2': [9, 8]}, index=['Ana', 'Bob'])
notas_hist = pd.DataFrame({'examen': [8, 9], 'proyecto': [7, 10]}, index=['Ana', 'Bob'])
resultado = notas_mat.join(notas_hist)

# Equivalente con merge
resultado = pd.merge(notas_mat, notas_hist, left_index=True, right_index=True)

pd.pivot() y pd.pivot_table()

Reorganiza datos de formato largo a ancho. pivot_table permite agregaciones.

# Pivot básico
temperaturas = pd.DataFrame({
    'ciudad': ['Lima', 'Lima', 'Cusco', 'Cusco'],
    'mes': ['Ene', 'Ene', 'Ene', 'Ene'],
    'temp': [22, 22, 18, 18]
})
df_pivot = temperaturas.pivot(index='ciudad', columns='mes', values='temp')

# Pivot con agregación
ventas = pd.DataFrame({
    'vendedor': ['Ana', 'Ana', 'Bob', 'Bob'],
    'producto': ['A', 'B', 'A', 'B'],
    'monto': [100, 200, 150, 250]
})
tabla = pd.pivot_table(ventas, values='monto', index='vendedor', columns='producto', aggfunc='sum')

pd.melt()

Convierte un DataFrame de formato ancho a largo (des-apila columnas).

# Melt (unpivot)
notas = pd.DataFrame({
    'alumno': ['Ana', 'Bob', 'Carlos'],
    'Matemáticas': [8, 9, 7],
    'Historia': [9, 8, 10]
})
notas_largo = pd.melt(
    notas,
    id_vars=['alumno'],
    var_name='asignatura',
    value_name='calificacion'
)

Accesor .dt

Permite acceder a componentes de fechas directamente desde una columna datetime. Es muy útil para extraer año, mes, día, día de la semana, etc.

# Crear columna de fechas
ventas = pd.DataFrame({
    'fecha': pd.to_datetime(['2024-01-15', '2024-03-20', '2024-07-05']),
    'monto': [100, 200, 150]
})

# Extraer componentes
ventas['año'] = ventas['fecha'].dt.year
ventas['mes'] = ventas['fecha'].dt.month
ventas['dia'] = ventas['fecha'].dt.day
ventas['dia_semana'] = ventas['fecha'].dt.day_name()
ventas['es_finde'] = ventas['fecha'].dt.dayofweek >= 5

# Filtrar por mes
enero = ventas[ventas['fecha'].dt.month == 1]

# Obtener el último día del mes
ventas['ultimo_dia_mes'] = ventas['fecha'].dt.days_in_month

Indexación con .loc

Selecciona filas y columnas por etiqueta (nombre). Es la forma más segura y explícita de acceder a datos en pandas.

# Seleccionar fila por etiqueta
df = pd.DataFrame({
    'nombre': ['Ana', 'Bob', 'Carlos'],
    'edad': [25, 30, 35],
    'ciudad': ['Lima', 'Cusco', 'Arequipa']
}, index=['a', 'b', 'c'])

# Seleccionar una fila
fila = df.loc['a']

# Seleccionar rango de filas
filas = df.loc['a':'b']

# Seleccionar fila y columna específica
valor = df.loc['b', 'edad']  # 30

# Seleccionar múltiples columnas
subset = df.loc[:, ['nombre', 'edad']]

# Filtrar con condición
mayores = df.loc[df['edad'] > 28]

# Asignar valores
df.loc['a', 'ciudad'] = 'Trujillo'

Selección con .xs()

Selecciona datos por nivel en un MultiIndex. Es ideal para datos jerárquicos donde necesitas filtrar por un nivel específico.

# Crear DataFrame con MultiIndex
paises = ['Perú', 'Perú', 'Chile', 'Chile']
ciudades = ['Lima', 'Cusco', 'Santiago', 'Valparaíso']
idx = pd.MultiIndex.from_arrays([paises, ciudades], names=['país', 'ciudad'])

df = pd.DataFrame({
    'población': [1000000, 400000, 600000, 300000],
    'temperatura': [22, 18, 15, 16]
}, index=idx)

# Seleccionar por nivel 'país'
peru = df.xs('Perú', level='país')

# Seleccionar por nivel 'ciudad'
cusco = df.xs('Cusco', level='ciudad')

# Seleccionar con drop_level=False (mantiene el nivel)
lima = df.xs('Lima', level='ciudad', drop_level=False)

# xs con condición en múltiples niveles
resultados = df.xs(('Perú', 'Lima'), level=('país', 'ciudad'))

Manejo de fechas

pandas tiene herramientas poderosas para trabajar con fechas.

# Convertir strings a fechas
eventos = pd.DataFrame({
    'evento': ['Concierto', 'Feria', 'Exposición'],
    'fecha_str': ['2024-03-15', '2024-04-20', '2024-05-10']
})
eventos['fecha'] = pd.to_datetime(eventos['fecha_str'])

# Crear rango de fechas
semana = pd.date_range(start='2024-06-01', periods=7, freq='D')

# Operaciones con fechas
eventos['dia_desde_inicio'] = (eventos['fecha'] - eventos['fecha'].min()).dt.days

# Filtrar por rango de fechas
filtro = eventos[(eventos['fecha'] >= '2024-03-01') & (eventos['fecha'] <= '2024-04-30')]

MultiIndex

Permite tener múltiples niveles de índice para datos jerárquicos.

# Crear MultiIndex desde listas
paises = ['Perú', 'Perú', 'Chile', 'Chile']
ciudades = ['Lima', 'Cusco', 'Santiago', 'Valparaíso']
idx = pd.MultiIndex.from_arrays([paises, ciudades], names=['país', 'ciudad'])

# Crear MultiIndex desde un MultiIndex
idx2 = pd.MultiIndex.from_product([['A', 'B'], [1, 2]], names=['grupo', 'num'])

# Ver niveles
print(idx.levels)  # [['Chile', 'Perú'], ['Cusco', 'Lima', 'Santiago', 'Valparaíso']]

# Reorganizar niveles
df = df.swaplevel('país', 'ciudad')

Stack y Unstack

Cambian entre formato ancho y largo moviendo niveles de índice a columnas o viceversa.

# Crear DataFrame con MultiIndex de columnas
ventas = pd.DataFrame({
    ('Ene', 'A'): [100, 200],
    ('Ene', 'B'): [150, 250],
    ('Feb', 'A'): [120, 220],
    ('Feb', 'B'): [160, 260]
}, index=['Norte', 'Sur'])

# Stack: columnas a índice (ancho -> largo)
stacked = ventas.stack()

# Unstack: índice a columnas (largo -> ancho)
unstacked = stacked.unstack()

# Unstack nivel específico
unstacked = stacked.unstack(level=0)
